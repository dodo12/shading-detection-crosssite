# Figures

All figures are in `figures/` as PNG (300 dpi) and PDF, generated by `src/make_figures.py`.

| File | Content |
|---|---|
| `fig01_workflow` | Workflow: two datasets, site-specific healthy reference, normalised features, detectors, evaluations |
| `fig02_datasets` | Irradiance ranges of both datasets and number of samples per class |
| `fig03_signatures` | Relative loss, relative voltage and relative current by condition and site |
| `fig04_within_site` | Within-site AUC (three model families × four feature sets) with 95% block-bootstrap intervals |
| `fig05_cross_site` | Cross-site AUC in both directions for raw, normalised and loss-only features |
| `fig06_severity` | Relative loss for full vs partial shading (Brazil) and for the three shading types (La Réunion) |
| `fig07_localisation` | Balanced accuracy of panel identification from window-level features against chance |
| `fig08_robustness` | AUC under multiplicative noise and missing irradiance |
| `fig09_shap` | Mean absolute SHAP values of the XGBoost detector within Brazil |
